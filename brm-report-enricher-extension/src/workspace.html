Matching rules in this build

  • Name order must match exactly; only capitalization and extra whitespace are normalized.
  • If identical names appear more than once, wallet-only records are ignored.
  • The record with a POS account is preferred; terminal ID/serial is used to resolve multiple POS-bearing exact matches.
  • If more than one POS-bearing exact match still remains, the row is marked REVIEW instead of guessing.
